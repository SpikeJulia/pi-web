# Pi Studio — Context

Pi Studio is a local web workspace for the pi coding agent (enhanced fork of Pi Web): it reads pi session files, drives agent sessions over RPC, and provides project browsing, model config, skill management, and chat.

## Language

**Attachment**:
A file added to a chat message before sending. The client holds the `File` object until send time; no bytes leave the browser until then.
_Avoid_: Upload, file, 附件

**Upload**:
The act of persisting an attachment to the server at send time, producing an Upload Record.
_Avoid_: Attach, send-file

**Upload Record**:
The server-side result of an Upload: the original name, the stored name, the resolved path, MIME type, and byte size.
_Avoid_: File entry

**Original name**:
The user-visible filename carried by the `File` object. Never written to disk as a filename.
_Avoid_: Real name, friendly name

**Stored name**:
The on-disk filename generated by the server: 8 random bytes hex plus the original extension (e.g. `a1b2c3d4e5f6g7h8.pdf`).
_Avoid_: Safe name, hashed name

**Sidecar metadata**:
A `.meta.json` file written next to each Uploaded file, recording original name, MIME type, size, and upload time. Lets history rendering reconstruct chips from a random stored name.

**Upload directory**:
`<cwd>/.pi-uploads/<sessionId>/`, the per-session storage for every Uploaded file. Always git-ignored.
_Avoid_: uploads folder, temp dir

**Attachment channel**:
How a file reaches the model. An image channel carries the file inline (base64 in the images field); a path channel carries the file as a path reference in message text.
_Avoid_: Route, mode

**Path reference**:
Inline `@.pi-uploads/<sessionId>/<storedName>` text placed in the composed message for path-channel attachments. The agent resolves it with its own tools (read, bash).
_Avoid_: File pointer, tag

**Attachment chip**:
The UI element representing a pending or sent attachment: icon, original name, size, and a remove button (pending) or preview affordance (sent).
_Avoid_: File bubble, token

**Just-in-time upload**:
The design where Uploads happen when the user sends a message, never when they select a file.
_Avoid_: Deferred upload, lazy upload
